## 3. 构建证据与业务完成边界

- 2026-11-13 新增独立只读 CTP 行情采集代码：CLI 选项 9、AES-256-GCM 配置工具、
  MD-only 登录/合约订阅/显示和基于统一路径类的 Tick CSV；提供假 SDK 的离线全链路用例。
  **本轮尚未通过 LD 编译/用例及真实行情验证**，不据此关闭 B4/B5 或声明可替换旧系统。
  详见 [操作指南](CTP只读实时行情采集操作指南.md)。交易网关与四个正式交易入口仍禁用。
- 2026-11-13 已确定 `/data` 下四来源目录：`x_trader_data`、`historic`、`taobao`、`virtual_data`；
  [统一子目录与兼容设计](data_import_guide.md#统一数据目录约定2026-11-13)已更新为无“品种”层的布局。
  `market_data_paths` 首版独立编译及用例已有用户回传通过日志；CLI 浏览根目录已改接，
  默认采集目录并支持实际子目录选择，本轮改动待验证。
  回测准备菜单已增加来源、类型/文件、Virtual 占位项和 Run 配置传递，Run 只返回“施工中”，本轮待验证。
  读取器接口、导入/回测执行/录制实现未改；来源真实性/产品能力校验及旧数据迁移仍属第五阶段/B3/B5 未完成项。
- 2026-11-11 的同步与编译记录确认 Debug/Release 应用构建通过，详见执行修订计划第 7.8 节。
- 用户提供的 2026-11-13 日志再次确认 Release 构建及验收工具/用例的 Python 语法检查通过；帮助检查跳过，回归未运行。
- Python 语法检查不执行验收工具或测试，不产生交易验证结论。应用构建通过也不表示对应 C++ 单测已经编译或运行。
- 当前四个正式交易入口 `xtrader_replay`、`xtrader_paper`、`xtrader_ctp_sim`、`xtrader_live` 及 CTP 网关启动仍禁用；`--help` 不是交易验证。
- 旧 `execution_simulator` 仍禁用；独立离线撮合及账务组件的存在不表示它已接入正式回测入口。
- 当前没有完整验收通过的 B1–B8 批次。最新构建结果仅更新编译状态，不关闭合并表中的业务缺口。

**整体结论：**架构、模块基础、构建链路和部分离线组件已交付；第三至第五阶段仍存在实际业务开发与接线缺口，第六阶段最终替换验收未完成，不能认定为“仅剩测试”或“已可替换旧系统”。
